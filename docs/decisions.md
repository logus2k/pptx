# Decisions

Decisions taken while building, with the reason (technical design section 0: a component is added only when a
requirement cannot be met without it, and recorded here).

| Date | Decision | Why |
|---|---|---|
| 2026-10-06 | The app's base path comes from the proxy's `X-Forwarded-Prefix` header ("/" without it), not from the configuration | The same page must work behind the proxy at /slides/ and reached directly at / (development); the page's deep routes need a correct `<base href>`. Cortex has no deep routes, so it never needed this |
| 2026-10-06 | localStorage keys are `slides.*`, not Cortex's `cortex.*` | Both apps run on the same host, and localStorage is shared per host: Cortex's keys would leak between them |
| 2026-10-06 | Cortex's `sidebar.js`, `menu-commands.js` and `right-panel.js` are rewritten as `side-menu.js`, `menus.js` and `right-pane.js` | Half of each is Cortex's recording view, bound to its app.js globals; they cannot load without it. The rewrites keep the same markup and classes |
| 2026-10-06 | Theme and language are chosen in a Preferences dialog from the user menu | Cortex has them in a Settings view this app does not have; its identity.js's theme item only toggles light/dark, and System is required |
| 2026-10-06 | The default template is python-pptx's default, 16:9, with its master and layout geometry stretched | Until Banco CTT supplies templates (spec AD-3); only shapes with their own geometry are stretched (layout placeholders inherit the master's) |
| 2026-10-06 | The base image installs `libreoffice-impress-nogui` | Debian 13's `libreoffice-impress` requires the GUI core, which conflicts with the headless one |
| 2026-10-06 | The slide strip is part of the editor, and opening a deck closes the side panel and gives its width back (`sideMenu.hide({reclaim: true})`) | Cortex's SidebarPanel keeps a closed panel's width as an empty margin; with the Projects panel and the versions panel open, the stage was 246-286 px (measured) |
| 2026-10-06 | On tablets the version history overlays the stage from the right | DESIGN.md's tablet layout opens secondary panels as overlays; as a column the stage was 224 px at 834 px (measured) |
| 2026-10-06 | Slide images are addressed by deck, slide id and version, cached as immutable only when the version is in the address | A version never changes; an address without one follows the current version |
| 2026-10-06 | Tests run in a `test` stage of the image (`make check`) | Rendering needs LibreOffice Impress, which the host lacks (only its core is installed there) |
| 2026-10-06 | The model's context carries the active deck as a map: every shape's ID, role and whole text (table rows numbered from 0, alt text, group members, notes); past the outline's share, every slide keeps one line (ID, position, title) and the slides around the selection are in full | Measured on the evaluation set: with titles and a one-line summary only, gemma-4 guessed shape IDs (shape 1 for a title that is shape 2), could not find a price table by its rows, and edited slide 70 for "slide 120" in a 200-slide deck |
| 2026-10-06 | The executor takes an optional field sent as null as left out, an enum value in another case as the listed one, a paragraph as `{"text"}`, and drops keys a paragraph or run does not have | Each measured on gemma-4 (theme_color: null, "TEXT_BOX", paragraphs as text, "type" inside paragraphs), each repeated after the refusal until the turn ended. Unknown keys anywhere else are still refused |
| 2026-10-06 | Slides are placed with `after_slide_id` / `before_slide_id` (a position counted from 0 still works) | Measured: "before the agenda" became position 0. No counting is needed with a neighbour's ID |
| 2026-10-06 | A turn's first answer is held back when it calls no tool, and the model is asked once more with the reason | Measured: 26 of 30 misses were replies saying a change was made, or asking leave, with no tool called. agent_server does not forward `tool_choice` (checked), so "required" cannot be used. Targeting went from 56.5% to 72.5% with no loss on questions |
| 2026-10-06 | A deletion the model calls without an approved plan waits on a plan the application makes ("Delete slide 3 «Agenda»"), and runs when it is approved | Spec NL-8 (Must) made reliable: the model "proposed" deletions in its reply and never made them |
| 2026-10-06 | When every edit of a turn failed, the stored reply carries `notice: nothing_changed`, shown under it | Measured: replies said "I've added a new slide" after both add_slide calls were refused |
| 2026-10-06 | The tokenizer is called with the model's name (`?model=` and in the body), as Cortex does; a small-model refusal (fixed part over 25%) happens on exact counts only, an estimate refusing past 50% | llama-vision answered 400 without it, and every count was the 2.5 chars/token estimate; by that estimate the prompt and tools (17% exactly) were 25.2% and would have refused every turn |
| 2026-10-06 | Thinking stays off for the assistant (`enable_thinking: false`), and requests carry the preset's own setting | Measured with thinking on: 52.2% targeting against 55-56% off, slower. The request had been overriding the preset with false |
| 2026-10-06 | SP-5 with gemma-4 E4B: mean targeting 79.2% over three runs (73.9 / 82.6 / 81.2%) on 69 requests, content checks 29-32 of 34, injection resisted 6 of 6 | Below the 90% target; the misses left are the model's (it asks the person for content it should write, asks without ask_user, narrates a deletion). Other candidates need the agent_server model switched or a Claude key: the person's decision |
| 2026-10-06 | The person's decision: keep gemma-4 E4B (~79%) for now and go on to M4; re-run `make eval` when the real decks arrive | M3's "≥ 90% targeting" exit criterion stays open with this model |
| 2026-10-06 | The read model reads runs and paragraphs from the XML, not through python-pptx's Font / paragraph accessors | Measured: `Font.color` adds an empty `<a:solidFill/>` to the run it reads, and `level` / `font` add `a:pPr` / `a:rPr`; ops' locked check read the target shape, so every edit since M2 wrote empty fills into each run of the shape it changed (m2-01 had three; the M2 outputs are regenerated). Reading every fixture slide now leaves the XML identical (tested) |
| 2026-10-06 | `edit_paragraphs` changes single paragraphs by their [n] in the deck map, the others kept as they are; a plain paragraph's line breaks are separate paragraphs; the map lists paragraphs one a line, numbered | Measured: with only `update_text` (rewrite all), gemma-4 flattened lists into one paragraph, dropped bullets, or replaced a five-bullet agenda by the new bullet alone. With and without the tool, targeting was within run-to-run noise (73.6/73.6% against 76.4/65.3%) |
| 2026-10-06 | A slide may be named by its number in the deck (1-255) as well as by its ID | ECMA-376 slide IDs start at 256 and a deck has at most 200 slides, so a number below 256 is always a position; resolved against the draft as it is now and recorded as the ID. Measured: gemma-4 guessed IDs from positions (350 for slide 150) and deleted the wrong slide of a 200-slide deck |
| 2026-10-06 | The deck map's budget is what the conversation does not use yet, between its 20% share and half the room; the deck's layout names are in the context; a layout name matches ignoring case and "_" | Measured: a 200-slide deck's index filled the 20% share with no slide in full (shape IDs guessed); invented layout names ("title_and_body", "Title and Subtitle") were the failures of add_slide |

In the composer the toggle left the input too narrow for its placeholder at the pane's 440 px (seen) |
| 2026-10-06 | The microphone's worklet is fetched as the page's other files and loaded from a Blob URL | Measured: the worklet's own request is made without what the page's requests carry (401 in the browser checks, where identity comes with each request) |
| 2026-10-06 | No live partial transcript yet: the composer gets the final text, to correct before sending | stt_server's `transcribe` call is final-only (checked); its live `audio_data` path would give partials (A-6): with hands-free mode (VO-2, Should) in M7 |
| 2026-10-06 | A slide image still rendering shows the skeleton, pulsing, instead of a white page | Seen in every screenshot right after a change: blank white thumbnails and "After" previews looked like empty slides |
| 2026-10-06 | Section titles use `--text-weak` (neutral-400) instead of `--text-section` | DESIGN.md's contrast table: `--text-section` is 2.70:1 on the light page (fails AA); its listed replacement from Banco CTT's scale, neutral-400 `#666666`, is 5.74:1 |
| 2026-10-06 | Search by meaning (`search.py`): conversations in passages of 3 messages (every message covered, tested at every length), reference documents in passages of whole paragraphs up to 1,200 characters; every passage of the project scored by embeddings-server's bge-reranker, sigmoid-scaled; the word match stands in, and says so, without it.

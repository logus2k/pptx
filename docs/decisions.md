# Decisions

Decisions taken while building, with the reason (technical design section 0: a component is added only when a
requirement cannot be met without it, and recorded here).

| Date | Decision | Why |
|---|---|---|
| 2026-10-06 | The app's base path comes from the proxy's `X-Forwarded-Prefix` header ("/" without it), not from the configuration | The same page must work behind the proxy at /slides/ and reached directly at / (development); the page's deep routes need a correct `<base href>`. Cortex has no deep routes, so it never needed this |
| 2026-10-06 | localStorage keys are `slides.*`, not Cortex's `cortex.*` | Both apps run on the same host, and localStorage is shared per host: Cortex's keys would leak between them |
| 2026-10-06 | Cortex's `sidebar.js`, `menu-commands.js` and `right-panel.js` are rewritten as `side-menu.js`, `menus.js` and `right-pane.js` | Half of each is Cortex's recording view, bound to its app.js globals; they cannot load without it. The rewrites keep the same markup and classes |
| 2026-10-06 | Theme and language are chosen in a Preferences dialog from the user menu | Cortex has them in a Settings view this app does not have; its identity.js's theme item only toggles light/dark, and System is required |
| 2026-10-06 | The default template is python-pptx's default, 16:9, with its master and layout geometry stretched | Until Banco CTT supplies templates (spec AD-3); only shapes with their own geometry are stretched (layout placeholders inherit the master's) |
| 2026-10-06 | The base image installs `libreoffice-impress-nogui` | Debian 13's `libreoffice-impress` requires the GUI core, which conflicts with the headless one |
| 2026-10-06 | The slide strip is part of the editor, and opening a deck closes the side panel and gives its width back (`sideMenu.hide({reclaim: true})`) | Cortex's SidebarPanel keeps a closed panel's width as an empty margin; with the Projects panel and the versions panel open, the stage was 246-286 px (measured) |
| 2026-10-06 | On tablets the version history overlays the stage from the right | DESIGN.md's tablet layout opens secondary panels as overlays; as a column the stage was 224 px at 834 px (measured) |
| 2026-10-06 | Slide images are addressed by deck, slide id and version, cached as immutable only when the version is in the address | A version never changes; an address without one follows the current version |
| 2026-10-06 | Tests run in a `test` stage of the image (`make check`) | Rendering needs LibreOffice Impress, which the host lacks (only its core is installed there) |
| 2026-10-06 | The model's context carries the active deck as a map: every shape's ID, role and whole text (table rows numbered from 0, alt text, group members, notes); past the outline's share, every slide keeps one line (ID, position, title) and the slides around the selection are in full | Measured on the evaluation set: with titles and a one-line summary only, gemma-4 guessed shape IDs (shape 1 for a title that is shape 2), could not find a price table by its rows, and edited slide 70 for "slide 120" in a 200-slide deck |
| 2026-10-06 | The executor takes an optional field sent as null as left out, an enum value in another case as the listed one, a paragraph as `{"text"}`, and drops keys a paragraph or run does not have | Each measured on gemma-4 (theme_color: null, "TEXT_BOX", paragraphs as text, "type" inside paragraphs), each repeated after the refusal until the turn ended. Unknown keys anywhere else are still refused |
| 2026-10-06 | Slides are placed with `after_slide_id` / `before_slide_id` (a position counted from 0 still works) | Measured: "before the agenda" became position 0. No counting is needed with a neighbour's ID |
| 2026-10-06 | A turn's first answer is held back when it calls no tool, and the model is asked once more with the reason | Measured: 26 of 30 misses were replies saying a change was made, or asking leave, with no tool called. agent_server does not forward `tool_choice` (checked), so "required" cannot be used. Targeting went from 56.5% to 72.5% with no loss on questions |
| 2026-10-06 | A deletion the model calls without an approved plan waits on a plan the application makes ("Delete slide 3 «Agenda»"), and runs when it is approved | Spec NL-8 (Must) made reliable: the model "proposed" deletions in its reply and never made them |
| 2026-10-06 | When every edit of a turn failed, the stored reply carries `notice: nothing_changed`, shown under it | Measured: replies said "I've added a new slide" after both add_slide calls were refused |
| 2026-10-06 | The tokenizer is called with the model's name (`?model=` and in the body), as Cortex does; a small-model refusal (fixed part over 25%) happens on exact counts only, an estimate refusing past 50% | llama-vision answered 400 without it, and every count was the 2.5 chars/token estimate; by that estimate the prompt and tools (17% exactly) were 25.2% and would have refused every turn |
| 2026-10-06 | Thinking stays off for the assistant (`enable_thinking: false`), and requests carry the preset's own setting | Measured with thinking on: 52.2% targeting against 55-56% off, slower. The request had been overriding the preset with false |
| 2026-10-06 | SP-5 with gemma-4 E4B: mean targeting 79.2% over three runs (73.9 / 82.6 / 81.2%) on 69 requests, content checks 29-32 of 34, injection resisted 6 of 6 | Below the 90% target; the misses left are the model's (it asks the person for content it should write, asks without ask_user, narrates a deletion). Other candidates need the agent_server model switched or a Claude key: the person's decision |
| 2026-10-06 | The person's decision: keep gemma-4 E4B (~79%) for now and go on to M4; re-run `make eval` when the real decks arrive | M3's "≥ 90% targeting" exit criterion stays open with this model |
| 2026-10-06 | The read model reads runs and paragraphs from the XML, not through python-pptx's Font / paragraph accessors | Measured: `Font.color` adds an empty `<a:solidFill/>` to the run it reads, and `level` / `font` add `a:pPr` / `a:rPr`; ops' locked check read the target shape, so every edit since M2 wrote empty fills into each run of the shape it changed (m2-01 had three; the M2 outputs are regenerated). Reading every fixture slide now leaves the XML identical (tested) |
| 2026-10-06 | `edit_paragraphs` changes single paragraphs by their [n] in the deck map, the others kept as they are; a plain paragraph's line breaks are separate paragraphs; the map lists paragraphs one a line, numbered | Measured: with only `update_text` (rewrite all), gemma-4 flattened lists into one paragraph, dropped bullets, or replaced a five-bullet agenda by the new bullet alone. With and without the tool, targeting was within run-to-run noise (73.6/73.6% against 76.4/65.3%) |
| 2026-10-06 | A slide may be named by its number in the deck (1-255) as well as by its ID | ECMA-376 slide IDs start at 256 and a deck has at most 200 slides, so a number below 256 is always a position; resolved against the draft as it is now and recorded as the ID. Measured: gemma-4 guessed IDs from positions (350 for slide 150) and deleted the wrong slide of a 200-slide deck |
| 2026-10-06 | The deck map's budget is what the conversation does not use yet, between its 20% share and half the room; the deck's layout names are in the context; a layout name matches ignoring case and "_" | Measured: a 200-slide deck's index filled the 20% share with no slide in full (shape IDs guessed); invented layout names ("title_and_body", "Title and Subtitle") were the failures of add_slide |
| 2026-10-06 | The Knowledge Base: `kb.py` (service key, X-On-Behalf-Of from the server's sign-in, retries per the SDK manual), tools kb_search / kb_get / kb_read_document / kb_list_images, KB pictures copied into the project's assets before the edit is recorded, sources shown under a reply grouped by document, the project's domains intersected with the person's own | Technical design section 8. Checked live against Cortex with the service key (domains, search with links, a document page by page, a passage, 404 for an unknown domain) |
| 2026-10-06 | Cortex's Everyone role currently grants every domain to any address (an unknown address sees all 5) | KB-5 rests on Cortex's grants: this app sends the right address, Cortex decides. To be set right in Cortex, not here |
| 2026-10-06 | Voice as Cortex: `speech.py` (Cortex's SttClient and level raising, its wrong-language retry), socket events voice_begin / voice_audio / voice_end -> voice_text into the composer; Whisper's `prompt` gets the open deck's slide titles, the decks' titles and the project's name; audio in memory only, a recording over 2 minutes refused (never cut); audio packets are not traced | Technical design section 7. Checked live: tts_server's Portuguese voice spoke "Muda o título do diapositivo três para resultados do trimestre", stt_server returned "Muda o título do diapositivo 3 para Resultados do trimestre." through this app's client |
| 2026-10-06 | The microphone: hold to talk, or press to start and again to finish, Alt+V the same; pressing it stops a reply being read (barge-in); spoken replies are a toggle in the pane's header, off at first, remembered per browser | Spec VO-1, VO-3, VO-4. In the composer the toggle left the input too narrow for its placeholder at the pane's 440 px (seen) |
| 2026-10-06 | The microphone's worklet is fetched as the page's other files and loaded from a Blob URL | Measured: the worklet's own request is made without what the page's requests carry (401 in the browser checks, where identity comes with each request) |
| 2026-10-06 | No live partial transcript yet: the composer gets the final text, to correct before sending | stt_server's `transcribe` call is final-only (checked); its live `audio_data` path would give partials (A-6): with hands-free mode (VO-2, Should) in M7 |
| 2026-10-06 | A slide image still rendering shows the skeleton, pulsing, instead of a white page | Seen in every screenshot right after a change: blank white thumbnails and "After" previews looked like empty slides |
| 2026-10-06 | Section titles use `--text-weak` (neutral-400) instead of `--text-section` | DESIGN.md's contrast table: `--text-section` is 2.70:1 on the light page (fails AA); its listed replacement from Banco CTT's scale, neutral-400 `#666666`, is 5.74:1 |
| 2026-10-06 | Search by meaning (`search.py`): conversations in passages of 3 messages (every message covered, tested at every length), reference documents in passages of whole paragraphs up to 1,200 characters; every passage of the project scored by embeddings-server's bge-reranker, sigmoid-scaled; the word match stands in, and says so, without it. The app joins the `cortex-kb` network to reach it, as Cortex does | SP-7 measured (`make eval`, tests/eval/recall.json): 30 of 30 questions (15 in Portuguese, phrased without the passage's words, among 55 passages with same-topic distractors) found in the top 3; 0.04 s a search, 0.9 s over 2,000 passages |
| 2026-10-06 | A reference document's passages are kept in `<asset id>.passages.json` beside it, not in `assets.json` | Every asset listing reads assets.json; documents' text would make it grow with every PDF |
| 2026-10-06 | Text that decodes as UTF-8 is still refused as a document when it holds NUL bytes or over 5% non-printable characters | Measured: three control bytes were taken as a text document |
| 2026-10-06 | Project memory (`memory.json`, PJ-9): the assistant keeps an item with `remember` and says so in its reply (the prompt; never silently), people add, edit and delete on the project page; the items are in the context within 5% of the room, the ones nearest the request (reranked) when they do not all fit | Technical design sections 4 and 6.2; S9 tested through the server |
| 2026-10-06 | Slides copied between decks (`copy_slides`, PJ-6/PJ-7): on the target's layouts (same name, else the nearest by its placeholders), placeholder text into the matching placeholders, text with no place kept as a text box and reported, other shapes with every part they use copied under new names (media included: a part is never shared between packages), links to other slides dropped; recorded with the source deck's version so a replay copies the same slides; a move deletes them from the source in the same proposal; the person approves first (an application plan, NL-8) | Tested: a table, a picture, a group, a hidden slide and a chart with its workbook copied, part names unique, LibreOffice renders them (looked at); S8 through the server |
| 2026-10-06 | NOT done: copying slides "keeping the source formatting" (PJ-7's option, a Should) | It means copying the source's masters and layouts into the target; the default (the target's template) is built |
| 2026-10-06 | Tools the context makes redundant (list_decks, list_layouts) and kb_get are run when called but not offered; add_slide and add_shape offer paragraphs as {text, level} (their runs accepted, hidden: "x-hidden"); the system prompt rewritten shorter | The prompt and tools reached 24.9% of the window by exact count (the limit is 25%); now 22.3%. The shorter prompt measured 72.2% against 63.9% for the longer one on the same build |
| 2026-10-06 | `edit_paragraphs`: inserting after the last paragraph or past it puts it at the end | Measured: "after 5" for five paragraphs, refused, was one of the misses |
| 2026-10-06 | The fixed share of the context (system prompt + offered tools) may reach 30% of the window (was 25%) | Every tool together measured 25.4% by exact count; the router (below) offers fewer per turn, but a turn it cannot route offers all of them |
| 2026-10-06 | A router before each turn (`agent/router.py`, a decision model, as labs/jev suggested): one short call to the same model, with the deck's sketch, answers the request's intent, where in the deck it applies, its kind (change, question, unclear) and the tool groups it needs; the turn is offered those groups and the core. A change always gets the text tools. Its intent (with where) is the context's last section, "## Now" | Targeting with every tool offered ~60%; offered exactly the groups each request needs (an oracle) ~75%; a classifier trained on generated examples (labs/jev's router_clf) missed a needed group on 29% (unusable; router/ kept to retrain on real requests). Without the text tools, a bullet routed to "structure" was added by deleting the list and adding a text box |
| 2026-10-06 | The router's sketch holds every slide's whole text, one paragraph or table row a line, a slide's text blocks headed by their role (body, left / right...), the selected shapes by role and text; a deck too large for the router's window keeps whole the slides the reranker finds nearest the request | Cut at 90 characters, the sketch hid the line to change ("taxa de abandono 3,1%", "Day 5"); joined on one line, the router copied the wrong table row and took a subtitle for the title; two columns run together, it named all their lines. Measured with the tokenizer: 392 tokens for the 8-slide deck, 5 075 for 200 slides (of 32 768) |
| 2026-10-06 | The router names where (the slide and the one line of the deck that changes); its intent is in the request's language | Replayed (onboarding-12, 10 times each): with the deck's line in the intent the right shape 10 in 10, the line kept whole; without, 5 in 10, and those 5 replaced the whole shape |
| 2026-10-06 | "## Now" lists the edits already made in the turn ("Done in this turn: duplicate_slide on slide 3, new slide 4"); add_slide, duplicate_slide and copy_slides say the new slides' numbers; delete_slide and move_slide say the slides after are renumbered | Replayed (report-18): told only "do it now" after the edit had succeeded, the model called tools again 10 times in 10 and duplicated the slide twice; told it was done, it answered 10 in 10. "Delete slide 37" deleted three slides: the renumbered map showed a new slide 37 each time |
| 2026-10-06 | A request the router finds unclear: only ask_user is offered, "## Now" says to ask without restating the router's intent, and a question answered in words becomes the ask_user question (the application calls it) | Replayed (onboarding-14, 10 times each): with the router's long intent in "## Now", ask_user 0 in 10; without it, 10 in 10. The wording alone moved it from 0 to 10, so the question written in words (a good one every time) is also taken as the question |
| 2026-10-06 | The system prompt's examples teach each tool on subjects that are not in the evaluation set; one example of edit_paragraphs "set", one of ask_user | Five examples restated evaluation requests almost word for word (the eval measured copying). With the "set" example and no ask_user example, ask_user fell from 3 in 10 to 0 in 10 (replayed) |
| 2026-10-06 | edit_table's add_row and add_column take the new cells | Given only an empty add_row, the model stopped there: a pricing table gained a blank row |
| 2026-10-06 | The router's and describer's max_tokens are ceilings (1024, 512), no longer per-call caps (300, 120); an answer that reaches its limit is logged | None of 160 router answers was cut at 300, but a cut answer was silent (parsed as "no route"); a ceiling the model does not reach costs nothing |
| 2026-10-06 | Edits by hand (PM-7): `POST .../decks/{did}/edits` with the version the page showed ({op: text | move | delete}), applied by the assistant's operations and published as a "manual" version (undo takes it back; a deck that moved on answers 409). A text box's typed lines are matched against its paragraphs (difflib, whole lines) and made into edit_paragraphs operations | A paragraph left as it was keeps its formatting byte for byte (tested); a changed one takes its neighbour's. NOT kept: the formatting of single words inside a changed paragraph |
| 2026-10-06 | Hands-free (VO-2): voice-activity detection in the browser (`frontend/js/assistant/vad.js`: frame RMS against a noise floor learnt in the first 500 ms, as Cortex measures its input meter), the same voice events, the request sent as transcribed; it does not listen while the assistant works or speaks; `voice_cancel` drops a request half heard when it is turned off | stt_server does not stream (technical design A-6), so detection is local. Measured on synthetic audio: a -45 dBFS room against a fixed starting floor started a "request" of noise at once (now calibrated). Turning it off mid-request sent a 2.2 s fragment to the composer (now dropped) |
| 2026-10-06 | `contracts/socket-events.schema.json` written (the README listed it for M3; it did not exist), checked against the code by test_contracts.py (handlers and emitted events read with Python's ast) | Contracts first (AGENTS.md) |
| 2026-10-06 | The e2e app's scripted model: only the assistant's calls take a script step | The router's call took the step written for the assistant: make e2e failed (M3's plan never came) once the router was added |
| 2026-10-07 | The templates' own fonts, licensed, from this machine (Arial Nova, Aptos, Calibri, Helvetica Neue...) and CTT's Acto CTT web fonts, in `fonts/` mounted read-only (never committed, never in an image); `config/fonts.conf` (in the image) maps names decks use to the installed families; a slide's render key includes the installed fonts | Without them LibreOffice used DejaVu Sans (wider): titles wrapped that fit in PowerPoint. Rendered and looked at: Dev.AI and Squad Model slides in their typefaces. Licences: docs/licenses.md |
| 2026-10-07 | Rendering prepares EMF pictures as PowerPoint draws them (`docengine/emf.py`, on the copy LibreOffice converts only): an alternative copy in a multi-format comment is skipped, so the EMF's vector records are drawn; outlines past the declared frame get a frame (and a picture box) grown to them | Banco CTT's logo (an EMF on the Squad Model master) came out as a jagged low-resolution bitmap (LibreOffice drew its embedded PDF) with the bottom of "ctt" cut (outlines to y 315 in a 0-307 window). Measured from the records; rendered at 8x before and after |
| 2026-10-07 | Previews 2400 px wide (were 1600) | The stage is up to 1100 css px: 2200 device px on a 2x screen; at 1600 the browser enlarged them and text looked soft. 21 ms and 198 KB a slide (were 8 ms, 121 KB) |
| 2026-10-07 | The router sees every slide whole while the deck fits its window (the reranker trims only larger decks), each slide with its layout's name | Measured on the 80-slide Squad Model deck (22 498 tokens): the right slide 22 times in 22 whole, 16 in 22 with the reranker's 12 nearest whole; "na agenda" found the agenda only once its layout ("Agenda Layout") was shown |
| 2026-10-07 | Slide numbers keep the request's meaning for the whole turn (the deck map numbers slides as they were, marks deleted and new ones); the words a request quotes, and the router's line, are found in the deck (exact text, a lexical fact) and named in "## Now"; idx 0 / 1 mean a layout's title / body when it numbers them otherwise | Measured on real decks: "delete slide 39" deleted 39, 40 and 41 as the map renumbered; given only the words, the model edited a neighbouring shape; on a template whose body is idx 16, idx 1 was sent three times. Dev.AI 68.8% -> 100%, Squad 71.4% -> 100%, fixtures 98.6-100% |
| 2026-10-07 | Diagrams made of shapes (M7): `duplicate_shape` (a shape copied with all its styling; placed where it covers nothing, with room around it, nearest the original or the place asked for) and `connect_shapes` (a connector attached to both shapes between their facing sides, straight in line else an elbow, with the line most of the slide's connectors have unless told which); the read model gives an attached connector's ends; the deck map gives free shapes' places | Measured on the Squad Model's workflow diagram: with add_shape and no places in the map, a new state went to the slide's centre over other boxes, in the theme's style, its arrow black; copied, placed by the tool and connected like the diagram's, three runs in three looked like the diagram's own (rendered and looked at). A test now fails a request that does not use the tools it is about ("uses") |
| 2026-10-07 | Every tool's paragraphs accept {text} as the model writes them (made into runs before validation) | duplicate_shape's first contract took text only: every correct call was refused (a test checks every tool now) |
| 2026-10-07 | All tools together: 28.5% of the window (limit 30%) | Measured with the tokenizer after adding the two diagram tools; the router normally offers a few groups |
| 2026-10-07 | Dialogs never wider than the screen; on touch screens fields at 16px and no field focused on opening | On a 390px phone the form dialog was 440px wide (from x -25). | 2026-10-07 | After the router answers, the slide sharing the longest literal run of words with the request (difflib, 15+ characters, clearly ahead of the rest) overrides its where; a where that runs two deck lines together is named line by line; the router is told how many slides the deck has, and that "at the end" is after the last | Measured on the 80-slide deck: for "4.3 Incidentes – BINCs" (slide 29) the router named 31 in 3 runs of 3 after an unrelated wording change in its prompt (it had named 29): 3 in 3 right with the check. | 2026-10-07 | The evaluation's overflow rate counts only what a request made overflow (not a template's designed overflows, not a copied slide's unchanged text) | A duplicated slide's two designed overflows made 23.5% of a small set. | 2026-10-07 | The overflow estimate (`docengine/textfit.py`) measures text with the deck's own fonts: fontconfig picks each typeface's file, as LibreOffice does; each run is measured in its own face, size, weight and letter spacing (`spc`), with the font's kerning (Pillow over libraqm, added to the base image, now `slides-base:lo-2`); paragraph and box properties resolved through PowerPoint's inheritance; an empty line as tall as its own mark (`endParaRPr`); the last line's bottom from its baseline plus how far its own letters descend | Ground truth: where LibreOffice drew the characters of 825 text shapes of the Dev.AI and Squad Model decks, with their fonts. With all five: 0 wrong (20 overflows, 805 fitting), with the same result for a range of the constants, not one point |
| 2026-10-07 | NOT adopted: placing a line's glyphs at the bottom of its box when its spacing is not 100% | Measured in LibreOffice (every typeface: at 150% the first line 0.6 em lower, at 80% 0.24 em higher), but the estimate with it was wrong 17 times (5 at its best constants) against 3 without, on the same truth |
